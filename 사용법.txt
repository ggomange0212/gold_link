뮤뮤 링크 (MuMu Link) 사용법
==============================

OSLink처럼 휴대폰 앱에서 '뮤뮤 화면' 또는 'PC 바탕화면 전체'를 골라서 원격 조작하는 프로그램이에요.
- 화면: 영상 스트리밍 (최대 60fps)
- 조작: 진짜 터치 (드래그, 길게 누르기, 두 손가락 터치)
- 밖에서도 접속: Tailscale 같은 것 없이 PC 코드 + 비밀번호만 있으면 돼요.

폴더 구성
  PC\        -> PC에서 실행하는 프로그램
  android\   -> 휴대폰 앱 소스 (GitHub이 APK로 만들어 줘요)
  .github\   -> 자동으로 APK를 만드는 설정


[1] PC 프로그램 켜기
-------------------
1. 뮤뮤를 켜 두세요.
2. PC 폴더의 실행.bat 을 더블클릭하세요.
   - 처음 켤 때 화면 전송 모듈(scrcpy)과 외부 접속 모듈(cloudflared)을 자동으로 받아요.
   - Windows 방화벽 창이 뜨면 "허용"을 누르세요.
3. 검은 창에 나오는 "PC 코드"와 "비밀번호"를 기억하세요.
   - 둘 다 mumu_link_config.json 에 저장돼서 다음에도 그대로예요.
4. 이 검은 창을 닫으면 원격 조작이 꺼져요.


[2] 휴대폰 앱 만들기 (처음 한 번만, PC에서 하면 편해요)
-------------------------------------------------
1. github.com 에 가입하고 로그인하세요.
2. 오른쪽 위 + -> New repository -> 이름 아무거나 (예: mumu-link)
   -> Private 선택 -> Create repository
3. "uploading an existing file" 링크를 누르고,
   이 zip을 푼 폴더 안의 내용(PC, android, .github, 사용법.txt)을 통째로 끌어다 놓으세요.
   -> 아래 "Commit changes" 클릭
   ※ .github 폴더가 안 보이면(숨김 폴더) 아래 [문제 해결] 1번을 보세요.
4. 위쪽 "Actions" 탭에 들어가면 빌드가 자동으로 시작돼요. (3~5분)
   초록색 체크가 뜨면 완료예요.
5. 저장소 첫 화면 오른쪽 "Releases"에서 MuMuLink.apk 를 휴대폰으로 받아 설치하세요.
   - 휴대폰 브라우저에서 GitHub에 로그인하면 바로 받을 수 있어요.
   - "출처를 알 수 없는 앱" 설치 허용이 필요할 수 있어요.


[3] 휴대폰으로 접속
-----------------
1. 뮤뮤 링크 앱을 열고 PC 코드와 비밀번호를 입력 -> 연결
2. 다음부터는 앱을 열면 자동으로 연결돼요.
3. 화면 위 동그란 버튼(드래그로 옮길 수 있어요)을 누르면 메뉴가 나와요.
   뒤로 / 홈 / 최근 앱 / 화질 / 전체화면 / 하단 버튼 / 새로고침 / 연결 끊기
4. 휴대폰 뒤로가기 버튼은 앱의 처음 화면으로 돌아가요.
   (뮤뮤에 뒤로가기를 보내려면 화면 아래 버튼이나 메뉴의 "뒤로"를 쓰세요)

앱 없이 크롬으로도 돼요:
  - 같은 와이파이: 검은 창에 나온 http://192.168.x.x:8770 주소
  - 밖에서: 검은 창에 나온 https://xxxx.trycloudflare.com 주소 (켤 때마다 바뀜)


[PC 바탕화면 조작]
- 기기 목록에서 "PC 바탕화면"을 누르면 PC 전체를 조작할 수 있어요.
- 탭 = 왼쪽 클릭 / 길게 누르기 = 오른쪽 클릭 / 끌기 = 드래그 / 두 손가락으로 끌기 = 스크롤
- 아래 버튼: 키보드(한글 입력 가능), Esc, 시작, 지우기, 엔터
- 메뉴: 창 전환(Alt+Tab), 바탕화면(Win+D), 복사, 붙여넣기, 한/영
- 다른 PC의 크롬으로 접속하면 마우스와 키보드를 그대로 쓸 수 있어요.
- 휴대폰을 가로로 돌리면 PC 화면이 크게 보여요.
- 관리자 권한으로 실행된 창(작업 관리자 등)은 조작이 안 될 수 있어요.
  필요하면 실행.bat을 마우스 오른쪽 -> 관리자 권한으로 실행하세요.

[옵션]  실행.bat 을 메모장으로 열고 "python mumu_link.py" 뒤에 붙이세요.
  --password 1234        비밀번호 바꾸기 (기존 로그인은 모두 풀려요)
  --new-code             PC 코드 새로 만들기 (코드가 유출됐을 때)
  --device 127.0.0.1:16384 --device 127.0.0.1:16416   뮤뮤 여러 개 등록
  --no-desktop           PC 바탕화면 조작 끄기 (뮤뮤만 보이게)
  --adb "경로\adb.exe"   adb 위치 직접 지정
  --no-tunnel            밖에서 접속 끄기 (같은 와이파이만)
  --port 8770            포트 바꾸기


[문제 해결]
1. GitHub에 .github 폴더가 안 올라갔을 때
   저장소에서 Add file -> Create new file -> 파일 이름에
   .github/workflows/build-apk.yml 을 입력하고,
   이 zip의 같은 파일 내용을 복사해서 붙여넣은 뒤 Commit 하세요.
2. 매크로가 자꾸 끊길 때
   매크로와 다른 버전의 adb를 쓰면 서로 연결을 끊어요.
   --adb 로 매크로가 쓰는 것과 같은 adb.exe를 지정하세요.
3. 화면이 안 나오고 "스크린샷 방식"이라고 뜰 때
   영상 방식이 실패해서 예비 방식으로 바뀐 거예요. (느리지만 동작해요)
   메뉴의 "새로고침"을 누르면 영상 방식을 다시 시도해요.
   계속 안 되면 검은 창의 메시지를 캡처해서 보여주세요.
4. 앱에서 "PC를 찾지 못했어요"
   PC 검은 창에 "주소를 등록했어요"가 떴는지 확인하세요.
   켠 직후라면 10~20초 기다렸다가 다시 연결하세요.

[보안]
- PC 코드와 비밀번호를 둘 다 알아야 접속할 수 있어요. 다른 사람에게 알려주지 마세요.
- 비밀번호를 5번 틀리면 1분 동안 막혀요.
- PC가 주소를 휴대폰 앱에 알려줄 때 무료 서비스 ntfy.sh를 거쳐요.
